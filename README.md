## Project Overview
This project applies Machine Learning to predict a football (soccer) player's future **G+A (Goals + Assists)** production based on their historical performance and underlying advanced metrics[cite: 7]. 

Live ON: https://football-future-ga-predictor.streamlit.app/[cite: 7]

By utilizing rolling data spanning three seasons (2023-2024, 2024-2025, and 2025-2026), the model forecasts a player's **G+A per 90 minutes for the upcoming 2026-2027 season**[cite: 7]. It transitions away from raw output and relies heavily on expected metrics (xG, xAG), progression stats, and custom-engineered consistency and momentum features to identify underlying talent rather than lucky outliers[cite: 7].

This project also includes a **Real-Time Interactive Dashboard** built in Streamlit, allowing scouts and fans to simulate player playing time and view expected outputs dynamically[cite: 7].

## Current State & Recent Updates
The project pipeline and application have been updated to address data discrepancies and ensure dashboard stability:
* **Progressive Stats Handling:** The pipeline now correctly proxies missing progressive carrying and passing stats (`PrgC`, `PrgP`, `PrgR`) for the 25-26 season by securely falling back to the 24-25 metrics, preventing `KeyError` crashes in the Streamlit app[cite: 5, 6].
* **Streamlit UI Safety:** Added explicit native `float` casting to the model's output to prevent `numpy.float32` typing issues, ensuring safe mathematical rendering and formatting in Streamlit[cite: 5].
* **Formatting Fixes:** Fixed f-string interpolation syntax for the rolling goal momentum metrics to properly render trend signs (e.g., `+0.15`)[cite: 5].
